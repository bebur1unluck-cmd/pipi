# Figma-прототип мобильного приложения SenseRoom

Этот каталог содержит dev-плагин для Figma, который автоматически создает полноценный high-fidelity прототип мобильного приложения по теме:

> «Разработка мобильного приложения дизайна интерьеров для начинающих дизайнеров».

## Как открыть в Figma

1. Откройте Figma Desktop или веб-версию Figma.
2. Создайте новый **Design file**.
3. Перейдите в меню **Plugins -> Development -> Import plugin from manifest...**.
4. Выберите файл `design/interior-app-figma-plugin/manifest.json`.
5. Запустите плагин **Interior Design Mobile App Prototype**.
6. Нажмите **Создать прототип в Figma**.

Плагин создаст страницу `Interior Design App - Figma prototype` с 18 экранами 390x844 и проставленными prototype links.

Если раньше уже была создана страница с пустыми экранами, удалите ее в Figma или запустите обновленный плагин еще раз: он создаст новую страницу с заполненными фреймами.

## Как проверить перелинковку

1. В Figma перейдите во вкладку **Prototype**.
2. Выберите экран `01 Домашняя страница`.
3. Нажмите **Present**.
4. Проверьте переходы:
   - `Домашняя страница -> Поиск дизайна -> Выбор объекта -> Дизайн комнаты/жилья -> Карточка проекта -> Избранное`;
   - `Домашняя страница -> Каталог идей -> Фильтры -> Карточка проекта`;
   - `Домашняя страница -> Специалисты -> Поиск по проблеме -> Инженеры/Дизайнеры -> Профиль мастера -> Заявка`.

## Что входит в макет

- дизайн-система: теплые интерьерные цвета, карточки, чипы, кнопки, нижняя навигация;
- домашний экран, каталог, фильтры по стилям/классу/критериям;
- алгоритм подбора дизайна для комнаты и жилья;
- раздел специалистов с инженерами и дизайнерами;
- карточка проекта, избранное и форма заявки специалисту;
- интерактивные переходы на кнопках, карточках, фильтрах и нижней навигации.
